# PROYECTO DE RELOJES
Este proyecto se creó para el estudio y adquerir conocimiento de varias clases y métodos referidos al tiempo.

## ESTÁ COMPUESTO POR 3 CLASES; TEMPORIZADOR, UN RELOJ NORMAL Y CRONÓMETRO.
- ### CRONÓMETRO
  En esta clase tenemos un cronómetro normal que puede guardar los tiempos y mismamente borrarlos si hiciese falta. Y tiene una característica especial y es que si quisieses podrías guardar tus tiempos en un archivo
  en tu escritorio llamado "Controlador_de_tiempo.txt" en el que se guardan los tiempos de esta forma: `00 : 00 : 01 tiempo añadido` || `00 : 30 : 61 tiempo añadido`.
  
- ### RELOJ
  En esta clase tenemos simplemente un reloj normal que indica la hora.
  
- ### TEMPORIZADOR
  En la clase Temporizador podemos elegir el tiempo que querramos (dentro de los tiempo existentes reales; ´23:59:59´ || ´00:00:01´) hasta que se acabe el tiempo. El temporizador se podrá parar y
  este guarda los tiempos. Con estos tiempos podremos también borrarlos.
